# MÉTODO N.A.V.E. — Framework de Execução de Projetos de Branding

Extraído dos Módulos 3–7 do curso. **Não é um resumo do curso** — é o que se executa com cliente, do primeiro contato à entrega do guia de marca. O conteúdo de formação profissional (precificação, nicho próprio, vendas, mentalidade, bloqueio criativo) ficou de fora deliberadamente.

Cada afirmação carrega selo de evidência:

- `EXPLÍCITO` — ensinado literalmente no material
- `IMPLÍCITO` — aparece em exemplos, exercícios ou projetos
- `INFERÊNCIA` — dedução para conectar partes do método
- `LACUNA` — não está suficientemente explicado no acervo
